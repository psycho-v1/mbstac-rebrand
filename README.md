# MBSTAC — rebrand test

This repository holds layout and interaction tests for a possible refresh of the MBSTAC dApp.

It is maintained by **psycho-v1** in coordination with the operator of the official site. It is not a replacement for that site, and it is not an official release.

**Official dApp:** [https://mbasestack.com/](https://mbasestack.com/#mbasestack-utility-token)

## Do not use this build for live activity

Please do not connect a funded wallet, mint, claim, or treat balances shown here as authoritative.

This copy exists so the layout, navigation, and feature set can be reviewed in public. RPC reads, wallet prompts, and mint calls may be incomplete, rate-limited, or pointed at the wrong environment while tests continue.

When the work is accepted, it will be published by the owner on the official website. Until then, use only:

https://mbasestack.com/

## What this preview includes

The same visitor tasks as the live site:

- Community Branch and Branch A RPC selection
- Wallet address entry and dashboard-wallet connect
- Compare Balances and Compare Claims
- Source amounts (Purchase, Bonus, Total)
- Contact details required before mint
- Custom or maximum MBSTAC mint
- Contract address copy and explorer link
- FAQ

MBSTAC remains a utility record of dashboard Purchase and Bonus. It is not BDAG and it is not offered here as an investment.
